# Mat Görsel Pro 1.1
Android 8+. GitHub Actions üzerinden debug APK derleme. Dosyaları depo köküne yükleyin. .github/workflows/apk.yml dosyasının da yüklendiğini doğrulayın. Actions > Mat Gorsel Pro APK > Run workflow veya push sonrası çalıştırma > Artifacts > Mat-Gorsel-Pro-APK. ZIP içindeki app-debug.apk dosyasını çıkarın.
SVG raster önizleme, PDF ve PDF uyumlu AI, Android bitmap biçimleri, ZIP içindeki seçili görseller, PNG/JPEG dışa aktarma. GIF/WebP animasyonu Android 9+; dışa aktarma ilk kareyi kullanır. EPS/PS, TIFF, PSD ve ICO için özel çözücü yoktur. HEIC/AVIF cihaz ve Android sürümüne bağlıdır. Derleme ve cihaz testi yapılmamıştır.

## v1.2 çevrimiçi seçenek
EPS, PS, TIFF, PSD, ICO ve yerelde açılamayan AI/HEIC/AVIF için kullanıcı onayıyla CloudConvert tarayıcıda açılır. Otomatik API entegrasyonu yoktur. Dosyayı elle yükleyin, PNG olarak indirin ve uygulamada Aç ile seçin. ZIP içindeki dosyayı önce Dosyayı kaydet seçeneğiyle dışarı çıkarabilirsiniz. Hizmetin format, kota ve ücret koşulları değişebilir. Android derlemesi test edilmemiştir.
